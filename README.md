# Store World

منصة سوق خدمات ومواهب عربية RTL، مع تجربة Marketplace وAI Hub.

## النسخة الحالية
- واجهة Landing حديثة ومتجاوبة.
- Marketplace categories.
- بحث وتصفية للمواهب حسب الخدمة أو الفئة.
- حفظ المواهب المفضلة محليًا في هذا المتصفح.
- بطاقات مواهب.
- AI Hub وتجربة مساعد ذكي تجريبية.
- نماذج واجهة تجريبية للحسابات، دون مصادقة فعلية أو إرسال بيانات.
- تصميم RTL مع قابلية إضافة الإنجليزية.
- لا توجد قاعدة بيانات أو مدفوعات حقيقية بعد؛ هذه مرحلة MVP للواجهة والتجربة.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشر المستودع عبر GitHub Pages.

## خارطة الطريق
1. المصادقة وحسابات العميل/المستقل.
2. قاعدة البيانات والملفات والرسائل.
3. المشاريع والعروض والمراحل والمدفوعات.
4. AI matching وAI utilities.
5. لوحة الإدارة والثقة والأمان.
6. ربط مزود دفع حقيقي بعد تجهيز المتطلبات القانونية والتجارية.
